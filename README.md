# Website Desa

Repositori dokumentasi dan pengembangan **SIDESA — Sistem Informasi Desa Terpadu (Website Desa)**.

## Dokumentasi

| Dokumen | Kode | Deskripsi |
|---|---|---|
| [Software Requirements Specification](docs/SRS-Website-Desa.md) | SRS-WDESA-001 | Spesifikasi kebutuhan perangkat lunak lengkap: lingkup, kebutuhan fungsional & non-fungsional, model data, aturan bisnis, use case, ketertelusuran, pengujian, roadmap, dan risiko |

## Ringkasan Lingkup Sistem

Portal resmi desa yang mencakup profil desa, manajemen konten, transparansi APBDes, statistik desa,
layanan administrasi surat daring, kanal pengaduan masyarakat, PPID dan produk hukum, direktori
UMKM/BUMDes, serta panel administrasi berbasis peran (RBAC).
